# Mumble frontend docs

Start here:

- [`design-system.md`](./design-system.md) is the source of truth for current frontend implementation.
- [`design-prompt.md`](./design-prompt.md) is a short external-design brief derived from the current system.
- `design-from-claude/` is archived reference material and may describe older shadcn/Card-era decisions.

When editing frontend code, prefer current `src/` primitives and `design-system.md` over older screenshots, prompts, or generated design exports.
